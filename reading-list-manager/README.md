# リーディングリスト整理 (reading-list-manager)

Chrome標準の**リーディングリスト**を、数が増えても整理できるようにする拡張機能。

標準のリーディングリスト(サイドパネルの「リーディングリスト」)は「未読」「既読」の2区分で
並べるだけなので、数十件を超えると目的の記事が探せず、古いものが溜まる一方になる。
この拡張は**標準のリーディングリストそのものを読み書き**しつつ、次の機能を足す。

- **全画面の一覧**: 左に「表示・絞り込み・フォルダ・サイト・タグ」、右に表のような一覧を並べた画面。
  サイドパネルと同じデータ・同じ操作で、件数が多いときはこちらで整理する
- **フォルダとドメインでの自動振り分け**: フォルダごとに「入れるサイト」を書いておくと、
  今あるものもこれから追加するものも自動でフォルダに入る(下記)
- **サイトのアイコン(ファビコン)**: 開いたことのないサイトも、サイトから取りに行って表示する。
  見つからなければ頭文字で出す(下記)
- **検索**: タイトル・URL・タグ・メモを横断。全角/半角・大文字/小文字の違いは無視
  - `#タグ` … そのタグが付いたものだけ
  - `site:ドメイン` … そのサイトのものだけ(行のドメイン名を押しても同じ)
  - `-語` … その語を含むものを除外
  - 例: `#仕事 site:qiita -入門`
- **タグ・メモ・スター**: 1件ごとにタグ(複数)・メモ・スターを付けられる
- **絞り込み**: 未読/既読/すべて、★スター、**放置中**(未読のまま30日以上。日数は設定で変更)、
  **重複候補**、タグなし、タグ(複数選ぶとすべて付いたものだけ)
- **並び替え・まとめ表示**: 新しい順/古い順/タイトル順/サイト順、フォルダごと/サイトごと/タグごと/追加月ごと。
  まとまりの見出しを押すとたためる
- **一括操作**: チェックで選んで、既読/未読、スター、フォルダへ移す、タグを付ける/外す、削除。
  Shift+クリックで範囲選択、「表示中のN件をすべて選択」、まとまりの見出しのチェックでまとめて選択
- **削除の取り消し**: 削除直後に出る「元に戻す」で、タグ・メモ・元の追加日ごと戻せる
- **重複候補の洗い出し**: `?utm_source=…` などの計測用パラメータ、`#` 以降、末尾の `/`、
  `http`/`https`、`www.` の違いだけのURLを同じものとみなしてまとめて表示
- **追加の手段**: 右クリック「このページ/リンク先をリーディングリストに追加」、
  ショートカット `Alt+Shift+R`、サイドパネル上部の「今のページ」欄の「＋ 追加」
- **アイコンに未読数**(設定でOFFにできる)
- **エクスポート/インポート**: JSON(タグ・メモ・フォルダと振り分けルール込みのバックアップ)、CSV(Excel用、BOM付き)

## 使い方

1. `chrome://extensions` → デベロッパーモードON → 「パッケージ化されていない拡張機能を読み込む」で
   **`manifest.json` が直接入っているこのフォルダ**(`chrome-extensions/reading-list-manager`)を選択
2. ツールバーの拡張アイコンを押す(または `Alt+Shift+L`)と**サイドパネル**が開く。
   サイドパネルは**読むための一覧**だけ(下記)
3. 整理するときは**全画面**で開く。どれでも同じ画面になる(すでに開いていればそのタブに切り替わる)
   - サイドパネルの検索欄の右にある「全画面で整理」ボタン(一覧のいちばん下のリンクも同じ)
   - ツールバーのアイコンを右クリック →「全画面で開く」
   - ショートカット `Alt+Shift+F`
   - 設定の「ツールバーのアイコンを押したとき」を「全画面」にすると、アイコンを押すだけで全画面になる
     (そのときサイドパネルは、アイコンの右クリックメニュー →「サイドパネルで開く」)
4. 一覧のタイトルを押すと開く。既定では新しいタブで開いて既読にする(設定で変えられる)。
   Ctrl(⌘)+クリック・中クリックは裏のタブで開く
5. 行にマウスを乗せると **★ / 既読 / 削除**(全画面ではさらに **編集**)のボタンが出る。
   編集ではタイトル・フォルダ・タグ・メモを変えられる(タグは入力して Enter、`Ctrl+Enter` で保存、`Esc` でやめる)
6. キーボード: `/` で検索欄へ、`Esc` で編集をやめる → 選択を解除 → 検索をクリア

### サイドパネルと全画面の役割分担

| | サイドパネル(読む) | 全画面(整理する) |
| --- | --- | --- |
| 一覧 | アイコン・タイトル・サイト名・追加日。新しい順 | URLのパス・フォルダ・タグ・メモ・放置/重複の印まで表示 |
| 絞り込み | 検索と、未読 / 既読 / すべて | 左の一覧で、絞り込み・フォルダ・サイト・タグ。並び替え・まとめ表示 |
| 行の操作 | ★ / 既読 / 削除(元に戻せる) | ＋ 編集(タイトル・フォルダ・タグ・メモ) |
| まとめて操作 | なし | チェックで選んで既読・★・フォルダ・タグ・削除 |
| そのほか | 「今のページ」欄で今のタブを追加・既読に | フォルダと自動振り分けの設定、エクスポート/インポート、設定(右上の「⋯」) |

サイドパネルには拡張の見出しを出さない(Chromeのサイドパネル自体の見出しに拡張名が出て二重になるため)。
サイドパネルは幅が狭く、ページを見ながら横で使うものなので、ボタンや絞り込みを並べると
肝心のタイトルが読めなくなる。そこで整理の操作はすべて全画面に寄せ、サイドパネルは「次に読むものを選ぶ」だけにしている。
未読/既読の切り替えなど表示の好みは、サイドパネルと全画面で別々に覚える。

> サイドパネルにしているのは、ポップアップ(最大800×600)だと数百件の一覧が窮屈なうえ、
> 外をクリックしただけで閉じてしまうため。サイドパネルならページを見ながら整理できる。

### 全画面の画面

| 場所 | 内容 |
| --- | --- |
| 左: 表示 | 未読 / 既読 / すべて |
| 左: 絞り込み | ★スター / 放置中 / 重複候補 / タグなし(複数選ぶと「すべてに当てはまるもの」) |
| 左: フォルダ | すべて / 各フォルダ / 未分類。「振り分け設定」でルールを編集 |
| 左: サイト | 件数の多い順。「サイトを探す」で絞れる。行の右の「→」で、そのサイトの振り分け先フォルダを決める |
| 左: タグ | 件数の多い順 |
| 右: 一覧 | タイトルとURL(ドメイン+パス)、フォルダ、追加日、操作ボタン。上に今かかっている絞り込みが並び、× で外せる |

左の件数は「その欄の絞り込みだけを外したら何件になるか」。例えばフォルダ欄の件数は、
今の表示(未読など)・検索・サイトの絞り込みをかけたまま、そのフォルダを選んだときの件数。

### フォルダとドメインでの自動振り分け

フォルダには「入れるサイト」を書いておく。振り分け先は**保存しておかず、表示のたびにルールから決める**ので、
ルールを書き換えると、すでにリストにあるものもその場で振り分け直される(「既存分に適用」の操作は要らない)。

- **いちばん簡単な作り方**: 全画面の左の「サイト」で、サイトの行の右の「→」→ フォルダを選ぶ(または名前を入れて「作成」)。
  そのサイトのものが今あるものもこれからのものも、そのフォルダに入る
- **まとめて設定**: 「振り分け設定」(左のフォルダ欄の見出し、または「⋯」メニュー)。
  フォルダごとに入れるサイトを1行に1つ書く。下に「よく保存しているのに、まだ振り分けていないサイト」が出るので、
  そこからワンクリックでルールにできる
- ルールの書き方
  - `github.com` … サブドメイン(`gist.github.com` など)も含む。`https://` や `www.` は付けても付けなくてもよい
  - `qiita.com/tags/javascript` … そのページ以下だけ(`/tags/javascript/…`。`/tags/javascripts` は含まない)
  - 2つ以上に当てはまるときは、長く書いたほう(具体的なほう)が優先
- **手で移す**: 行の編集欄の「フォルダ」か、一括操作の「フォルダへ移す…」。手で移したものはルールより優先し、
  一覧では枠付きのバッジで区別する。「自動の振り分けに戻す」でルールに任せる状態に戻せる
- フォルダを消しても中のリーディングリストは消えない(手で移したものは自動の振り分けに戻る)

フォルダは1件につき1つ(タグは複数付けられる)。「どこに置くか」はフォルダ、「横断的な目印」はタグ、という使い分け。

### サイトのアイコン(ファビコン)

Chromeが持っているアイコン(`_favicon`)は**一度でも開いたページ**のものだけなので、
別のPCで追加したものや開いたことのないサイトは地球儀マークになってしまう。そこで次の順に探す。

1. Chromeのキャッシュ(そのページのURL、サイトのトップのURL)
2. サイトの `/favicon.ico` を直接読む
3. (設定でONにしたときだけ)Googleのファビコン取得サービス
4. どれも無ければ、ドメインの頭文字を色付きの四角で出す

見つけた結果はサイトごとに覚えておく(見つかったものは30日、見つからなかったものは3日)ので、
開くたびにサイトへ問い合わせることはない。設定の「サイトのアイコン」で探し方を選べる。

| 設定 | 通信 |
| --- | --- |
| Chromeが覚えているものだけ | しない |
| 見つからなければサイトから取得する(既定) | 各サイトの `/favicon.ico` を読みに行く(そのサイトを開くのと同じ相手にだけ) |
| それでも無ければGoogleのサービスから取得する | 上に加えて、**ドメイン名がGoogleに送られる**。社内システムのドメインなどを外に出したくなければ使わない |

### 確認はダイアログで出さない

一括削除の確認は選択バーの中に「削除する / やめる」を出す。1件ずつの削除は確認なしで消し、
代わりに画面下に「元に戻す」を出す。`confirm()` を使うと削除のたびに手が止まり、
大量に整理する用途に合わないため。

## データの持ち方

| 情報 | 保存場所 | 他のPC・スマホとの同期 |
| --- | --- | --- |
| URL・タイトル・既読/未読・追加日時 | Chrome標準のリーディングリスト | **される**(Chromeの同期がONなら) |
| タグ・メモ・スター・手で移したフォルダ | この拡張の `chrome.storage.local`(キー: `meta:` + URL) | **されない** |
| フォルダと振り分けルール | `chrome.storage.local`(キー: `folders`) | されない |
| 設定 | `chrome.storage.local`(キー: `settings`) | されない |
| サイトのアイコンの探した結果 | `chrome.storage.local`(キー: `faviconCache`) | されない |

- 標準のリーディングリスト側で消した(標準のサイドパネルや別のPCから消した)ものも、
  タグ・メモは**30日間は残してある**。同じURLを入れ直すとタグ・メモが戻る。30日を過ぎたら自動で片付ける
- 別のPCにタグ・メモ・フォルダを持っていくときは、JSONでエクスポート → 向こうでインポート。
  インポートは「無いものは追加、あるものはタグを足し合わせ、メモは空のときだけ入れる」動き。
  フォルダは名前で突き合わせ、同じ名前があれば振り分けるサイトを足し合わせる

## 権限

| 権限 | 使い道 |
| --- | --- |
| `readingList` | リーディングリストの読み書き。インストール時に「リーディングリストのエントリの読み取りと変更」と表示される |
| `storage` | タグ・メモ・スター・設定の保存 |
| `sidePanel` | 一覧をサイドパネルに出す |
| `contextMenus` | 右クリックメニューからの追加、アイコンの右クリックメニュー(全画面/サイドパネルで開く) |
| `tabs` | サイドパネル上部の「今のページ」欄で、開いているタブのタイトル・URLを読む。全画面のタブがすでに開いていれば切り替える |
| `favicon` | 一覧にサイトのアイコンを出す(Chromeが持っているキャッシュ) |

外部への通信は、サイトのアイコンを探すときだけ(上記。設定で止められる)。

## 調査: 拡張機能でリーディングリストをどこまで扱えるか

Chrome 120 から `chrome.readingList` API(Manifest V3 のみ)が使える。調べた結果をまとめておく。

### API でできること

| 操作 | API | 備考 |
| --- | --- | --- |
| 全件・条件で取得 | `query({ url?, title?, hasBeenRead? })` | 条件は**完全一致**だけ。部分一致・全文検索は拡張側で作る(この拡張は全件取ってから絞り込む) |
| 追加 | `addEntry({ url, title, hasBeenRead })` | 同じURLがあるとエラー。http/https 以外(`chrome://` など)は入れられない |
| 更新 | `updateEntry({ url, title?, hasBeenRead? })` | 変えられるのは**タイトルと既読/未読だけ** |
| 削除 | `removeEntry({ url })` | |
| 変更の監視 | `onEntryAdded` / `onEntryRemoved` / `onEntryUpdated` | 標準のUIや別のPC(同期)での変更も拾える |

1件が持つ情報は `url`・`title`・`hasBeenRead`・`creationTime`・`lastUpdateTime` の5つだけ。

### API ではできないこと(と、この拡張での扱い)

| できないこと | この拡張での扱い |
| --- | --- |
| タグ・フォルダ・メモ・お気に入りを持たせる | 拡張の保存領域にURLをキーにして別に持つ。**標準のサイドパネルやスマホには出ない** |
| 標準のリーディングリスト画面(サイドパネル)を変える | 不可。この拡張は自前の画面(サイドパネル/タブ)を出す |
| URLを書き換える(URLがキー) | 不可。必要なら削除して追加し直すしかない |
| 追加日時(`creationTime`)を指定する | 削除の取り消し・インポートで戻すときは、元の追加日を拡張側に持って表示に使う |
| 並び順を決める・保存する | 標準側の並び順は保証されない。拡張側で並び替える |
| ページ本文を保存してオフラインで読む | 不可(標準のリーディングリストもPC版では本文を保存しない) |
| スマホ(Android/iOS)のChromeで使う | スマホのChromeは拡張機能が動かない。リーディングリスト本体は同期されるが、タグ・メモは見えない |
| タグ・メモを他のPCと自動で同期する | `chrome.storage.sync` は全体で約100KB・1キー8KB・最大512キーの制限があり、数百件のタグ・メモには足りないので使っていない。JSONのエクスポート/インポートで移す |

### 今後足せそうなもの(未実装)

- **タイトル・キーワードでの自動振り分け**: 今はドメイン(とパス)だけ。タイトルの語でも振り分けられるようにできる
- **リンク切れチェック**: 全サイトへのアクセス権限(`host_permissions`)が要るので見送り
- **本文の全文検索・要約**: ページの中身を取りに行く必要があり、同じく権限が大きくなる
- **ブックマークへの移動**: `bookmarks` 権限を足せば「読み終わったものをブックマークのフォルダへ移す」はできる
- **アドレスバーからの検索**: `omnibox` で `rl キーワード` のように検索できる
- **期限・リマインド**: `alarms` + `notifications` で「放置中が◯件あります」と知らせる
