Chrome Extension

Privacy Policy / プライバシーポリシー

Last Updated / 最終更新日: October 17, 2026

English

1. Overview

Reading List Manager values your privacy. This extension is designed to operate locally within your browser and does not collect, store, sell, or transmit any of your personal information, reading habits, or browsing history to external servers.

2. Data Storage

  • Reading List Items: Stored directly in Google Chrome's native Reading List via the chrome.readingList API.
  • Tags, Notes, Folders & Settings: Stored locally on your device using Chrome's local storage (chrome.storage.local).
  • No user data is ever uploaded to external servers or any third-party analytics/advertising services.

3. Network Requests & Third Parties

  • By default, the extension communicates directly with websites only to retrieve their favicons (/favicon.ico).
  • If you opt into the optional "Google Favicon Service" in settings, only the website domain name (e.g. example.com) is sent to Google's public favicon service (https://www.google.com/s2/favicons). You can disable this anytime.
  • The extension contains no tracking codes, no analytics, and no advertising libraries.

4. Permissions Justification

  • readingList: Required to read, add, update, and remove items from Chrome's native Reading List.
  • storage: Required to save user-defined tags, notes, folder rules, and preferences locally.
  • sidePanel: Required to display the reading list within Chrome's native side panel.
  • contextMenus: Required to provide quick actions ("Add page", "Add link", "Open full screen") from the right-click menu.
  • tabs: Required only to identify the active tab's URL/title for shortcuts (Alt+Shift+R) and to avoid opening duplicate manager tabs.
  • favicon: Required to display website favicons stored by Chrome.

日本語

1. 基本方針

「リーディングリスト整理」(Reading List Manager) は、利用者のプライバシーを最優先に考えて開発されています。本拡張機能はブラウザ内でローカルに完結して動作し、個人情報、閲覧履歴、読書データを外部サーバーに収集・保存・転売・送信することは一切ありません。

2. データの保存場所

  • リーディングリスト項目: Chrome標準の chrome.readingList APIを通じて、ブラウザ本体に保存されます。
  • タグ・メモ・フォルダ設定: Chromeのローカルストレージ (chrome.storage.local) を使用し、お使いの端末内にのみ安全に保存されます。
  • 外部サーバーへの送信・同期は行われません。

3. 外部通信および第三者サービス

  • デフォルトでは各サイトのファビコンを取得するため、該当ドメインの /favicon.ico のみを直接読み込みます。
  • 設定で「Googleのファビコン取得サービス」を有効にした場合に限り、ドメイン名（URL全体や個人情報は含まれません）が Google の公開API (https://www.google.com/s2/favicons) に送信されます。本機能は設定からいつでも無効にできます。
  • 広告配信、アクセス解析ツール、トラッカーは一切含まれていません。

4. 権限（Permissions）の利用目的

  • readingList: Chrome標準のリーディングリストの取得、追加・削除、既読状態更新に必須です。
  • storage: タグ、メモ、フォルダ振り分けルール、設定をお使いのPC内に保存するために利用します。
  • sidePanel: Chrome標準のサイドパネルUI内にリーディングリストを表示するために利用します。
  • contextMenus: 右クリックメニューから「このページを追加」「リンク先を追加」「全画面で開く」を実行するために利用します。
  • tabs: ショートカットキー（Alt+Shift+R）で現在開いているページのURL/タイトルを取得する際、および全画面表示時に既存タブを探して二重起動を防ぐためにのみ利用します。
  • favicon: Chromeがキャッシュしている各Webサイトのファビコン画像を表示するために利用します。
